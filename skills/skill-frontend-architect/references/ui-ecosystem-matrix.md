# UI Ecosystem & Component Library Reference Matrix

This reference document contains the curated catalog of UI libraries, frameworks, animation engines, and design toolkits with direct links, installation commands, and specific prompting strategies for AI-assisted engineering.

---

## Complete Tools & Libraries Matrix

| Tool Name | Type (Typ) | Description (EN) | Description (PL) | Links (Docs/Repo) | Quick Install / Setup | AI Context / Strategy (For Prompting) |
|---|---|---|---|---|---|---|
| **shadcn/ui** | Code Generator / Component Injection | Copy-paste accessible components built on Radix UI and Tailwind CSS. | Kopiuj-wklej: w pełni dostępne komponenty (Radix + Tailwind). | [Web](https://ui.shadcn.com/) \| [Repo](https://github.com/shadcn-ui/ui) \| [Docs](https://ui.shadcn.com/docs) | `npx shadcn@latest init` / `npx shadcn@latest add [component]` | **Code Injection:** `shadcn/ui` is NOT a dependency in `node_modules`. It places source code directly in `/components/ui`. Instruct AI to output compatible file structures or suggest the CLI command rather than importing from `shadcn/ui`. |
| **Tailwind CSS** | Utility-First CSS Engine | Utility-first CSS framework for rapid UI styling with zero runtime overhead. | Framework CSS typu Utility-first. | [Web](https://tailwindcss.com/) \| [Repo](https://github.com/tailwindlabs/tailwindcss) \| [Docs](https://tailwindcss.com/docs/installation) | `npm install -D tailwindcss postcss autoprefixer` | **Styling Engine:** Strictly enforce utility classes and 8-point grid scales. Avoid arbitrary values (e.g., `w-[34px]`) unless strictly justified by external asset constraints. |
| **Radix UI** | Headless Primitives | Unstyled, accessible UI primitives (logic and accessibility without predefined aesthetics). | Komponenty bezstylowe (czysta logika i dostępność bez narzuconego CSS). | [Web](https://www.radix-ui.com/) \| [Repo](https://github.com/radix-ui/primitives) \| [Docs](https://www.radix-ui.com/primitives/docs/overview/introduction) | `npm install @radix-ui/react-[component-name]` | **Headless:** AI MUST provide complete styling (Tailwind/CSS) because Radix components have no styles out of the box. | **Aceternity UI** | Animated Components | Copy-paste animated components using Framer Motion and Tailwind CSS. | Animowane komponenty (kopiuj-wklej) oparte na Framer Motion i Tailwind. | [Web](https://ui.aceternity.com/) \| [Docs](https://ui.aceternity.com/components) | `npm i framer-motion clsx tailwind-merge` (plus specific component deps) | **Copy-Paste:** Instruct AI to browse the specific component URL on Aceternity, analyze the source code, and adapt it to the current Tailwind config. Never hallucinate fake npm package imports. |
| **Magic UI** | Animated Sections & Blocks | Eye-catching hero sections, background animations, and landing page interactive blocks. | Efektowne sekcje Hero i interaktywne bloki landing page. | [Web](https://magicui.design/) \| [Repo](https://github.com/magicuidesign/magicui) \| [Docs](https://magicui.design/docs) | `npx magicui-cli@latest add [component]` | **Copy-Paste / CLI:** Similar to shadcn/ui. Instruct AI to identify the component name and provide the CLI command or exact code adaptation rather than guessing animation math. |
| **HeroUI (NextUI)** | React Component Suite (Tailwind) | Beautiful, fast, and modern UI library based on Tailwind and React Aria. | Piękny, szybki i nowoczesny UI oparty na Tailwind CSS i React Aria. | [Web](https://heroui.com/) \| [Repo](https://github.com/heroui-inc/heroui) \| [Docs](https://heroui.com/docs/guide/introduction) | `npm install @heroui/react framer-motion` | **Component Library:** Ensure `HeroUIProvider` is configured at root layout. Focus on visual aesthetic and design tokens. |
| **daisyUI** | Tailwind CSS Plugin | Semantic component classes for Tailwind CSS (e.g., `btn-primary`, `card`). | Klasy komponentów dla Tailwind CSS (np. `btn-primary`). | [Web](https://daisyui.com/) \| [Repo](https://github.com/saadeghi/daisyui) \| [Docs](https://daisyui.com/components/) | `npm i -D daisyui` | **CSS Classes:** Instruct AI that this is a Tailwind plugin. It should use `btn`, `card`, `badge` classes alongside standard Tailwind utilities without extra React imports. |
| **Flowbite** | Tailwind Library & Interactive JS | Interactive components built on Tailwind CSS with React wrappers. | Interaktywne komponenty zbudowane na Tailwind CSS. | [Web](https://flowbite.com/) \| [Repo](https://github.com/themesberg/flowbite) \| [Docs](https://flowbite.com/docs/getting-started/introduction/) | `npm install flowbite flowbite-react` | **Hybrid:** For React/Next.js projects, use `flowbite-react` components. | **Ant Design** | React Enterprise Suite | Enterprise-class UI with heavy data tables, complex forms, and internationalization. | Biblioteka klasy Enterprise, zoptymalizowana pod skomplikowane formularze i tabele. | [Web](https://ant.design/) \| [Repo](https://github.com/ant-design/ant-design) \| [Docs](https://ant.design/components/overview/) | `npm install antd` | **Enterprise Library:** Strictly follow Ant Design v5 API. | **Mantine** | React Library + Hooks Ecosystem | Comprehensive library with 100+ accessible components and 50+ custom hooks. | Ogromna biblioteka: 100+ komponentów i 50+ hooków. | [Web](https://mantine.dev/) \| [Repo](https://github.com/mantinedev/mantine) \| [Docs](https://mantine.dev/getting-started/) | `npm install @mantine/core @mantine/hooks` | **Ecosystem:** Utilize Mantine's built-in hooks (`useDisclosure`, `useForm`, `useMediaQuery`) alongside UI components. | **BlueprintJS** | React Desktop UI (Palantir) | Optimized for complex, data-dense desktop analytics interfaces. | Optymalizacja pod gęste dane i interfejsy typu desktop (np. analityka). | [Web](https://blueprintjs.com/) \| [Repo](https://github.com/palantir/blueprint) \| [Docs](https://blueprintjs.com/docs/) | `npm install @blueprintjs/core` | **Desktop-First:** Best for non-mobile apps and data density. Instruct AI to use Blueprint's specific CSS classes/props for layout. Warn AI that this library is not mobile-first. |
| **PrimeReact** | React UI Suite (Rich Data) | Rich component suite with advanced grids, tree-tables, charts, and rich-text editors. | Bogaty pakiet komponentów (Zaawansowane siatki, Wykresy, Edytory). | [Web](https://primereact.org/) \| [Repo](https://github.com/primefaces/primereact) \| [Docs](https://primereact.org/installation/) | `npm install primereact primeicons` | **Data-Dense:** Use for complex data tables (filtering, sorting, lazy pagination). | **Material UI (MUI)** | React Suite (Google) | Standard Material Design 2/3 implementation with robust theming. | Standardowa implementacja Material Design (Google). | [Web](https://mui.com/) \| [Repo](https://github.com/mui/material-ui) \| [Docs](https://mui.com/material-ui/getting-started/) | `npm install @mui/material @emotion/react @emotion/styled` | **Component Library:** Instruct AI to use the `sx` prop for one-off styles and `styled()` for reusable styled components.
