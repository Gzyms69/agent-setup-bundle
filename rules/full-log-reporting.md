# Full Log Reporting

When presenting diagnostic findings:

1. Include COMPLETE relevant log output -- do not truncate or summarize.
2. Include timestamps from logs to establish timeline.
3. Highlight specific error lines with analysis.
4. Provide exact commands used to obtain logs (reproducibility).
5. If logs exceed reasonable length: save as artifact and link.
6. NEVER paraphrase error messages -- quote them verbatim.
7. When reporting command output: show the FULL output, not just
   "it returned an error". The user needs to see what happened.
8. For multi-step diagnostics: present findings as a structured table
   with columns: Step | Command | Result | Analysis.
